# うぃーすた全国交流会 — Astro リニューアル案

うぃーすた全国交流会の既存コンテンツをベースに、幾何学的な図形、大胆なタイポグラフィ、スクロールに連動する表示演出を使って再構成したAstroサイトです。

## デザインの考え方

- 大きな見出しと余白で、最初にメッセージが伝わる構成
- 円・半円・リング・四角形などの幾何学的な装飾
- 白黒のチェック柄をベースに、コーラル・イエロー・ブルーグリーンをアクセントにした配色
- 配色プリセットは `src/data/theme.ts` の `activePalette` で切り替え可能
- スクロール時のフェードインと、ふわりと浮くヒーロー装飾
- 「うぃーすたについて」ページは、スクロール位置で背景の色面・幾何学模様が切り替わるストーリー構成
- スマートフォンでの読みやすさと操作性を優先
- 特定イベントサイトのロゴ・文章・画像・CSSをコピーせず、レイアウトの雰囲気を参考にした独自実装

## ページ

## 起動

Node.js 18.20.8以上、またはNode.js 20.3.0以上を推奨します。

```bash
npm install
npm run dev
```

## 本番ビルド

```bash
npm run build
npm run preview
```

## 編集箇所

- 開催回・日程・会場・連絡先・SNS：`src/data/site.ts`
- お知らせ：`src/data/news.ts`
- プログラム：`src/data/program.ts`
- FAQ：`src/data/faq.ts`
- 各ページの文章とレイアウト：`src/pages/` 内の `.astro`
- 共通CSS：`src/styles/global.css`
- ヘッダー・フッター：`src/components/`

すべてのCSS・JavaScriptは複数行で整形しています。外部WebフォントやCDNを使わず、システムフォントで表示するため、ローカル環境でもオフライン環境でも同じフォント構成で動作します。

## オフライン

本番ビルド後、HTTPSで初回アクセスするとService Workerが主要ページをキャッシュします。ブラウザとホスティング環境の制約上、初回キャッシュ完了前の完全オフライン起動はできません。

ローカル開発サーバーは `npm run dev` で起動できます。依存関係インストール後は、開発サーバー自体にネット接続は必要ありません。

## 配色の変更

`src/data/theme.ts` の `activePalette` を変更すると、サイト全体の配色を切り替えられます。

```ts
export const activePalette = "checker" as const;
```

使用できるプリセットは `checker`、`coral`、`blue`、`lavender` です。色を細かく決める場合は、同じファイル内の各パレットにあるHEX値を変更してください。`checker` は白と黒をベースに、アクセントカラーを重ねた初期案です。

## 「うぃーすたについて」のスクロール演出

`src/pages/about/index.astro` に演出用マークアップとスクリプト、`src/styles/global.css` に背景レイヤーとタイポグラフィを記述しています。画面中央に来たセクションの `data-about-scene` 属性に応じて、背景が約1.5秒で切り替わります。冒頭のロゴ表示、スクロール案内、スマートフォン用レイアウト、`prefers-reduced-motion` にも対応しています。
